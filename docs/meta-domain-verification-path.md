# Vérification de domaine Meta — accès direct

La documentation Meta indique que la vérification de domaine se gère dans **Business Settings → Brand Safety → Domains**. L’accès direct traditionnel à cette rubrique est : `https://business.facebook.com/settings/owned-domains`.

Pour le domaine Weurseuk, la balise de vérification est déjà servie publiquement : `facebook-domain-verification` avec la valeur `s740xu2sxqhvtjdvo5k9q9mqwjfimd`. L’action restant à effectuer est donc la validation dans l’interface Meta, sous un portefeuille professionnel auquel l’administrateur a accès.

## Validation confirmée — 20 août 2026

Dans le portefeuille professionnel **WeuRSeuK**, l’interface Meta affiche `weurseuk.com` avec le statut vert **Verified**. Le domaine est donc bien détenu et vérifié par ce portefeuille ; aucune action supplémentaire de vérification de domaine n’est requise.
