# Module Télévision de l’accueil — contrôle du 20 août 2026

La page d’accueil présente désormais les onze sources de la sélection Télévision dans un module compact placé après les vidéos tendances. Les vignettes conservent les couleurs distinctives des chaînes et distinguent le Sénégal, l’international et les archives.

Chaque vignette ouvre la page Télévision avec la chaîne correspondante déjà sélectionnée. Le parcours a été vérifié avec iTV Sénégal : le lien de l’accueil a ouvert directement le lecteur et la fiche officielle de la chaîne Emedia.

Après le premier déploiement, l’aperçu servait le nouveau module alors que le contrôle public affichait encore la version antérieure de l’accueil. Une vérification de propagation reste nécessaire avant de qualifier définitivement le rendu public.

Après relance de publication, le 20 août 2026, le domaine public a bien servi le module Télévision. Les onze liens — RTS, 2STV, SenTV, TFM, Walf TV, iTV, Marodi TV, Evenprod, Canal Info News (archives), TV5MONDE et France 24 — apparaissent entre les vidéos tendances et les deux revues de presse. La présentation des cartes À la Une est demeurée inchangée.
